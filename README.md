# 🌐 Studying Web Development — Python & Django

> 🚀 **Meu laboratório de estudos focado em Desenvolvimento Web Full Stack (Udemy).**

Este repositório foi criado para documentar a minha evolução diária, exercícios e projetos práticos desenvolvidos ao longo de 18 seções de aprendizado intenso, cobrindo desde a estruturação de layouts até o desenvolvimento de aplicações dinâmicas com Django.

---

## 🗺️ Mapa de Progresso e Tecnologias

### 📑 1. HTML5 e CSS3 Foundations
* **Fundamentos de HTML5:** Estruturação semântica, cabeçalhos, listas, imagens e formulários.
* **Estilização com CSS3:** Seletores, Box Model, elementos flutuantes e layouts líquidos/fixos.
* **Recursos Especiais:** Flexbox, normalize CSS, cantos arredondados, degradês, transições e animações.

### 📱 2. Responsividade
* **Bootstrap 4:** Desenvolvimento de interfaces reativas, media queries, grids, componentes e flexbox aplicados a designs modernos.

### 🧠 3. Lógica e Interatividade (JavaScript & jQuery)
* **ECMAScript 2015 (ES6):** Manipulação de variáveis, arrays, funções, objetos literais, protótipos e eventos do DOM.
* **jQuery:** Navegação entre elementos da árvore DOM, efeitos visuais, manipulação dinâmica de CSS e eventos de formulários.

### 🐍 4. Back-end & Arquitetura (Python, SQL & Django)
* **Python Core:** Estruturas de dados (listas, tuplas), loops, orientação a objetos avançada (associação, agregação e composição) e tratamento de exceções.
* **Banco de Dados:** Estruturação, consultas e persistência de dados.
* **Framework Django:** Desenvolvimento utilizando o padrão arquitetural MTV (Model-Template-View), gerenciamento de rotas, blocos de herança e arquivos estáticos.
